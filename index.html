What format does my file need?
  • One Excel file, three sheets: the task-mining clicks (Case ID, User, Timestamp, Window title), the labels for a sample of titles (Window_Pattern, Step, and a Rater column when several people label; add a Round column when they re-label later), and the expert's statements, one per row
  • Or separate CSV files, selected together; a step-level log (Case ID, Activity, User, Start time) works too
  • Any case attributes you have, such as type or amount, so performers are compared fairly
  • At least 30 cases; user IDs instead of names keep it anonymous
